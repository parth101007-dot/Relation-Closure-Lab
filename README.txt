REFLEXIVE, SYMMETRIC AND TRANSITIVE CLOSURES — DML MICRO PROJECT
===============================================================

FILES
- index.html: Complete interactive website. No installation or internet connection is required.
- assets/: Screenshots used in the report and presentation.

HOW TO RUN
1. Extract the ZIP file.
2. Open this folder in Visual Studio Code.
3. Open index.html in a browser, or install/use the Live Server extension and click "Go Live".
4. Enter a set and ordered pairs. Click "Calculate closures".

PROJECT FEATURES
- Computes reflexive, symmetric, and transitive closures for a finite relation.
- Displays relation pairs and Boolean matrices.
- Uses Warshall's algorithm for transitive closure.
- Validates set elements and input pair format.
- Runs locally in the browser. No database, server, or external API is required.
