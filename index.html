4. What each closure guarantees

Reflexive closureEvery element relates to itself. Add all missing diagonal pairs (a,a).
Symmetric closureIf (a,b) exists, then (b,a) must exist. Add the reverse of every pair.
Transitive closureIf (a,b) and (b,c) exist, then (a,c) must exist. Repeat until stable.

Algorithm note

For the transitive closure, the program uses the Boolean form of Warshall’s algorithm: for each intermediate vertex k, update reachability i→j when i→k and k→j are both true.
